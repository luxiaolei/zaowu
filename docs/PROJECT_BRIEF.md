# 造物：项目说明

版本：0.1.0 / 2026-11-11。状态：产品蓝图 + 可运行本地引导试用。

## 一句话

一个记得孩子怎样探索过、知道此刻该提供什么帮助的 AI 共创伙伴；孩子用它做出能展示的小作品，家长能看见实际过程。

## 不可动摇的产品原则

1. **先了解孩子，再设计教学。** 记忆不是附加模块；每次规划必须读取当下任务相关的经历、偏好、技能证据与支持历史。
2. **孩子保留创作权。** 必须经历选择、尝试、修改和表达，不能用一句话换一份“AI 全包”的成品。
3. **作品优先，学习嵌在作品中。** 不以刷题数量、考试名次、证书或聊天时长为价值证明。
4. **事实、观察、推断分开。** “家长说喜欢海洋”“这次点选不正确”“可能需要分组支架”不是同一类记忆。
5. **不把失误变成人格。** 不记录“笨”“懒”“内向所以不会”等判断；不推断智商、心理疾病或家庭困境。
6. **供应商可替换。** DeepTutor 提供可用教学能力；Vivix 提供可选角色表现；任何一个不可用都不应让作品和学习记录消失。
7. **不靠贵的视频维持互动。** 先验证语音/轻量角色与真实创作，按价值触发实时角色与生图。

## 用户与设备

目标是中国大陆家长陪同 5–12 岁孩子，按 5–6、7–9、10–12 分层。年龄段只是起点，不替代实际任务证据。优先平板/电脑网页，手机支持短任务和家长查看；原生 App 在设备使用证据充分后再决策。

## 首次试用

不要求家长填完整履历。只选年龄段、2–3 个兴趣、已有创作经验、当下支持偏好。用一次真实项目获取初步证据，结束展示孩子做出的关键决定和下一次建议。

## 核心循环

想做什么 → 我为什么给这个建议 → 孩子决定 → 做出局部 → 看见效果 → 换一种办法/情境 → 表达理由 → 私密保存 → 更新证据 → 下次从这里出发。

## 为什么先发布本地试用

先让家庭能点开并完成作品，再验证“个性化真的改变了引导”是否可观察。当前没有自由对话和真正生成式模型；这是诚实标注的交互与教学机制试验，不能当成成熟 AI 教育产品或上线合规证明。
