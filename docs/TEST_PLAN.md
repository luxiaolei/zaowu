# 测试与验收

## 已执行自动化

`npm test`：Node 内置测试，覆盖证据、推荐、隔离、撤回、作品门槛、全部年龄/任务变式、输出转义和存储故障。执行结果记录在 `docs/VERIFICATION.md`，以实际运行数据为准。

`npm run check`：CSP/外部脚本/设备采集/明显凭据模式/关键文档存在检查。它不是完整安全扫描或合规审计。

`tests/browser_smoke.py`：Playwright/Chromium 检查主要完整旅程、手机宽度、浏览器刷新、历史/删除、插画下载、无意外网络请求、控制台错误。需要另装开发用 Playwright，不是运行时依赖。

## 学习者模型必测

未知不伪造了解；单次错不诊断；不同任务首次失误才触发更多支架；多次猜测只算一个首次机会；提示后正确不冒充独立；同题重复不能证明迁移；观察/不确定不评分；不同孩子不串；事件重放幂等；过期不引用；撤回后重算；兴趣不影响智力判断。

## 创作流程必测

不能跳过首个决定；任务未解决不能宣称完成；反思未选不能结束；生成/保存失败不说成功；恢复草稿；同一项目回退不丢进度；本地存储失败明确告知；恶意标题被转义；导出插画不带完整学习档案。

## 联网版新增阻断测试

跨家庭 child/project/job/evidence 访问全部 403；API Key 不入构建；提示注入不能授权工具；输出 plan/patch schema 失败可降级；超时先查而非重试重复付费；并发预算原子性；取消后的生成不回贴；审核前图片不显示；删除传播到索引/缓存/供应商；备份保留透明；直播关闭确认与账单对齐。

## 设备与无障碍

目标实机：iPad Safari、iPhone Safari、Android Chrome、桌面 Chrome/Edge。当前容器 Chromium 的桌面/移动视口测试不是 iOS/Android 真机验证。检查焦点可见、键盘操作、44px 级触控目标、读屏标签、reduce-motion、长文本与小屏布局。

## 教学与产品验证

先由内容专家/家长检查题意和误判风险，再在明确同意的家长陪同下做小规模可行性试用。对每一次建议记录证据和理由，观察孩子决定、尝试、修正、迁移及作品完成。不可从一次页面测试推断学习效果，也不把留存增长直接当教育成效。

## 发布标准

自动化全过、README 状态真实、没有真实儿童数据/密钥、Pages 实际可访问、已知限制可见。本地试用达到此标准仍不代表联网儿童服务获准上线。
