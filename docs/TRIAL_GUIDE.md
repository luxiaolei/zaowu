# 家长陪同试用手册

## 开始

打开在线试用或 `npm start` 的本地地址。选年龄段、兴趣、常做过的活动和这次需要的帮助，确认陪同。无需 API Key、注册或填写真实姓名。5–6 岁请由家长读题。

## 建议体验顺序

先挑一个项目：选主角、颜色，做一个小实验，换一个情境，再选一句反思。保存后去“我的作品”查看并下载 SVG 插画。回到首页看下一项目是否改变。

再试“插画工坊”：换场景、主角和配色。每个选择影响画面。这是程序化插画组合，不是真正 AI 生图。

家长空间：确认由家长操作，查看具体证据与下一次推荐理由；修改兴趣；把误点造成的观察标为“不作依据”；确认推荐重算。可导出本地 JSON，也可删除全部记录。

## 如何验证不是只换主题

用本地测试/合成档案验证：同样喜欢海洋，一个在不同数量任务需要帮助，另一个已有独立尝试；前者获得更明确支架，后者保留自主尝试。单次错误不会诊断缺口，重复同一内容不会刷成“掌握”。不要为了做实验故意让真实孩子失败。

## 结束后观察

孩子是否做了有意义的决定？是否看懂反馈？是否愿意修正？家长能否理解推荐依据？过程有没有替孩子代做、读题困难或误触？保存的是孩子的决定还是 AI 的成品？

不用评价“聪明不聪明”，也不要求孩子为了测试保持更长在线。没有完成可以退出，已有进度保留。

## 当前限制

没有真正 AI 自由对话、语音、实时数字人或模型生图；作品导出是 SVG 插画，不是完整游戏/动画网页。学习任务是有限模板；个性化规则未做教学有效性验证。记录只在本浏览器，不跨设备；无真实家长认证。最多保存 40 项项目、30 张插画与 500 条/90 天内证据，超出滚动移除，重要作品请下载。共享设备结束后删除记录。

在线 GitHub Pages 在不同网络/地区的可达性可能不同，未作大陆全网验证；本地运行是独立备选，不需要连接模型服务。
