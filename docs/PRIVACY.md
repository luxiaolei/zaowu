# 隐私、儿童安全与上线门槛

这是工程设计，不是法律意见或合规证明。适用规则与供应商协议需在实际上线地区、年龄和数据流确定后由合适的专业人员核查。不要复用聊天中的未经核实法律/价格结论。

## 当前试用的真实边界

只有静态网页和本地浏览器记录。不建账户；不收姓名、学校、生日、位置、面部、声音；不调用模型；无广告、跟踪分析、公共评论、私信和付款。

家长确认仅用于引导，不是身份认证或有效监护关系的技术核验。localStorage 未加密；共享同一浏览器的人以及同 origin 下有执行权限的其他应用可能读取。因此不适合存真实敏感履历，不可作为生产多租户隔离。正式服务应使用独立 origin、认证授权与服务端隔离。

托管方/CDN 会处理普通网络访问数据，可能包括 IP 和请求日志。不能把“学习记录不上传”写成“网站不产生任何网络数据”。试用没有 service worker，不声称完整离线能力或可可靠安装 PWA；manifest 只提供基础安装元数据。

## 真实联网上线的阻断项

1. 确定市场、年龄、监护授权与用途分项；试用同意不能自动升级为音视频/云端模型同意。
2. 逐项列明 ASR、TTS、LLM、生图、Avatar、存储、日志、分析的供应商、处理地区、数据类别与保留时长。
3. 取得相应年龄与地区 API 使用资格；不能用境外服务器/家长账号绕过终端用户资格限制。
4. 训练退出、DPA/分包方、删除机制、跨境传输与敏感数据要求完成核查。
5. 服务端家庭/孩子隔离、设备共享风险、导出二次确认、删除原始与派生数据、备份到期说明。
6. 儿童内容输入/输出审核、适龄交互、危险活动与敏感话题处理、必要时建议找家长/可靠成年人，不自称真人老师或医疗专家。
7. 提供明确的投诉、安全问题报告与暂停能力，不能只靠模型拒答。

## 记忆最小化

必要：粗年龄段、兴趣、项目事实、与当前学习相关的操作证据、家长明确设置的支持偏好。
禁止默认提取：家庭冲突、健康诊断、财务、宗教、精确位置、真实身份、心理画像、面部/声纹。偶然出现的敏感信息不得因为“个性化”而永久保存。

所有记忆区分事实/声明/假设，有来源/时效/可纠正性。禁止用羞辱、比较排名或依恋设计刺激更多使用。角色是创作搭档，不替代家庭关系。

## 保留与删除

试用：最多 500 条证据，90 天不参与计算并在保存时清理；最多 40 个项目和 30 张本地插画，超出会滚动移除，UI/README 需解释容量。下载文件由家庭自行管理；网页删除不撤回已经下载的副本。

生产：保留期限按用途设置，提供到期作业；删除从源记录传播到估计、摘要、向量、缓存、对象、队列和供应商。删除回执明确哪些立即完成、哪些受备份周期约束；不得虚假承诺抹除已经发生的不可逆训练。

## 公开开源边界

公开：代码、原创课程模板、合成 fixtures、匿名技术指标、明确授权的图片。
不公开：真实儿童档案、家长邮件、语音、照片、未批准作品、API Key、provider payload、内部账单。Issue 模板提醒提交者；维护者发现泄露先移除公开内容并处理凭据/历史风险，不只删除当前文件。
