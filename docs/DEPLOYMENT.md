# 运行与部署

## 本地

Node.js 22+。`npm start` 默认监听 127.0.0.1:4173，可用 PORT 改端口。零运行依赖，不需要 npm install；直接双击 HTML 不可靠，因为使用 ESM。

## 静态发布

`site/` 是完整发布目录。GitHub Pages workflow 先运行测试与静态检查，再上传仅 site/，不发布整个仓库或 server/。Pages 设置需选择 GitHub Actions。公开源码不意味着公开用户 localStorage；但托管平台会处理正常网络访问数据。

不在静态站点存 API Key。任何未来 LLM/图像/Vivix 调用走经过认证的服务端；不要为方便演示在前端加入个人密钥。

## 生产前

独立应用 origin；HTTPS；真正家庭/孩子认证与权限；数据区域/供应商适用资格；审核与预算服务；日志最小化；删除演练。Github Pages 试用不能直接升级成正式儿童后端。

## 变更与回滚

每个改动先单元测试，再浏览器旅程。更改 storage/schema/rubric 需明确迁移策略，不能静默丢失或重新解释历史。回滚站点代码不自动回滚用户数据；生产需双向兼容窗口与备份恢复演练。

## 观测

本次不加载分析 SDK。反馈通过家长主动提交的匿名结构化描述；不要让家长上传完整家庭档案到公开 Issues。未来观测 request id、版本、错误、用量、延迟，正文默认不入日志。
