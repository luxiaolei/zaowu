# 造物 · ZAOWU

**了解这个孩子的过去，陪他创造下一件作品。**

面向 5–12 岁孩子与家长的开源共创工作室。不是刷题机，不是换皮聊天框，也不替孩子一键做完作品。

[打开本地引导试用](https://luxiaolei.github.io/zaowu/) · [产品需求](docs/PRD.md) · [学习者模型](docs/LEARNER_MODEL.md) · [教学设计](docs/TEACHING_DESIGN.md) · [开发路线](docs/ROADMAP.md)

> **v0.1.0 是本地规则引导试用，不是真实大模型产品。** 可以完成三个创作项目、保存作品与学习证据、根据历史重新推荐，并使用本地插画工坊。尚未接通 DeepTutor、LLM、语音、Vivix 或云端生图；不需要 API Key，不产生模型调用费用。在线站点是否已发布，以 GitHub Pages 部署状态为准。

## 从哪里开始

家长先选择年龄段、兴趣、过去常做的事情，以及这次希望获得的支持方式。孩子选择项目，亲自决定角色和颜色，尝试两个不同情境的小任务，回顾方法并保存作品。家长空间可以检查推荐依据、撤回不准确的观察、修改偏好、导出或删除记录。

试用项目：

| 项目 | 作品与活动 | 观察的技能 |
|---|---|---|
| 天空运输队 | 飞艇插画、数量与分组小实验 | 比较数量；提示前后表现 |
| 会跳舞的花园 | 花园插画、重复规律与迁移 | 发现重复单元 |
| 小小故事导演 | 故事主角插画、顺序与因果选择 | 事件顺序；原因与结果 |
| 插画工坊 | 场景 × 主角 × 配色，可保存/下载 SVG | 创作选择，不算学科掌握证据 |

本版本的作品是可下载的矢量插画，不是自由生成的网页、完整动画或视频。任务名称表达创作主题，不承诺已经实现完整游戏编辑器。

## 核心：学习证据驱动，而非“记住聊天”

- **经历**：做过什么项目，选择、尝试、修正了什么。
- **兴趣与支持偏好**：来源清楚，可改变，不定义固定“学习风格”。
- **技能与缺口假设**：区分不知道、证据不足、首次独立完成、提示后完成；不因一次错误诊断能力。
- **教学决策**：历史影响主题、下一项目、提示方式与迁移任务；家长可看为什么。
- **可纠正的记忆**：撤回一条观察会即时重算摘要与推荐；数据不写入公开仓库。

试用规则并未经教育效果验证。`confidence` 是证据充分度提示，不是校准后的掌握概率。详情见 [学习者模型](docs/LEARNER_MODEL.md)。

## 本地运行（无第三方运行时依赖）

```bash
git clone https://github.com/luxiaolei/zaowu.git
cd zaowu
npm start
# 打开 http://127.0.0.1:4173
npm test
npm run check
npm run cost
```

需要 Node.js 22 或以上。本地开发服务仅监听回环地址；不依赖 Python、模型密钥或数据库。不要直接双击 HTML；ESM 应通过 HTTP 服务运行。

## 隐私和安全

公开的是代码、教学模板与合成测试数据，不是儿童数据。本地记录未加密，不适合多人共享浏览器；家长确认按钮不是认证系统。托管方仍会处理普通网页网络请求。试用版没有麦克风、摄像头、第三方分析、广告、公开作品墙或模型请求。

真实联网服务须先通过 [隐私与上线门槛](docs/PRIVACY.md)，不能把本地试用的确认视为以后上传数据的同意。不要把 API Key 放入前端。发现问题见 [SECURITY.md](SECURITY.md)。
