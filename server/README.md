# 服务端（设计起点，尚未上线）

当前 v0.1.0 没有在线 API。`schema.sql` 提供 PostgreSQL 租户、档案、项目和证据的起始设计，**未在目标数据库运行验证，不能作为生产迁移直接发布**。

下一阶段使用 FastAPI 或等效框架实现 docs/API.md。认证、家长授权、供应商准入、审核与预算前置，不能先接公开无认证 LLM 代理。DeepTutor 以固定版本适配器接入，不 fork 一个隐藏的第二学习者数据库。

SQL 的 RLS 示例依赖可信应用服务设置事务范围 family_id；它不是认证系统，数据库连接不能暴露给浏览器，服务角色不能任意绕过隔离。部署前加真实 role/grant、迁移测试、事务范围、连接池清理、备份/删除演练。
